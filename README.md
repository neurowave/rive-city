# Rive City

https://github.com/user-attachments/assets/d917a871-55de-4503-94e3-45cd3c843229

A drivable, procedurally generated city built entirely with the [Rive CLI](https://rive.app/docs/cli/overview):
a 3D world rendered with Rive's GPU canvas and WGSL shaders, a hovercar cockpit whose screens and HUD are
live Rive artboards (state machines, data binding, layouts), and a skyline of animated, clickable billboards
that are also live Rive artboards.

Everything in the scene is generated from source: RML markup for the artboards, AnimaScript for the
simulation and renderer, WGSL for the shaders, and Python tools for the city, the car and the textures.

## Run it

1. Install the Rive CLI:

   ```bash
   curl -fsSL https://releases.rive.app/cli/install.sh | sh
   ```

2. From this folder:

   ```bash
   rive . --aot
   ```

   This builds `build/rive-city.riv` and opens the preview window. `--aot` compiles the scripts ahead of
   time (much faster at runtime). The first build takes a little while; later ones are cached.

The repository ships the generated files (`scene.rml`, `world.as`, compressed mesh packs in `assets/`), so
no Python is needed just to run it. Tested with Rive CLI 1.5.1 and newer.

### Troubleshooting

- **`script tier: interp, no wamrc`** in the log means the ahead-of-time compiler wasn't found, so scripts
  run in the interpreter. Everything still works, just at a lower frame rate. Point `RIVE_WAMRC` at a
  `wamrc` binary to enable it.
- **`script heap grew … MB over 120 frames`** appears once while the city loads (the mesh packs are
  decompressed into memory). It's a one-off allocation, not a leak, and the warning can be ignored.

## Controls

| Input | Action |
|---|---|
| Enter / Space / click | start (title screen) |
| W A S D / arrows | drive (takes over from autopilot) |
| P | autopilot |
| F | sky lane |
| M | drive mode |
| C | camera: cockpit / chase |
| O | showroom camera |
| H | hide / show the HUD |
| N | day / night |
| T | next track |
| E | stop at the playable billboard ahead, and play it |
| Esc | leave the billboard |
| R | back to the title |
| drag | look around |
| click | interact with screens and billboards |

The quality switch (top left) trades resolution and effects for speed: HIGH, MED, LOW.

## How it's built

| Piece | Where |
|---|---|
| Artboards (title, cockpit screens, HUD, billboards), view models, state machines | generated by `tools/gen.py` (+ `gen_ui.py`, `gen_bb.py`) into `scene.rml` |
| Simulation, camera, picking, renderer | `tools/world_parts/*.as.part`, assembled into `world.as` by `tools/build_world.py` |
| Shaders | `lit.wgsl` (HDR forward pass: city, car, billboards, traffic, steam, rooms behind windows), `taa.wgsl`, `bright.wgsl`, `blur.wgsl`, `shafts.wgsl`, `final.wgsl` |
| City (street grid, towers, billboards, traffic routes) | `tools/make_city.py` -> `assets/city.bin`, `cityinfo.as` |
| Hovercar exterior + cockpit (SDF modelled) | `tools/make_props.py`, `make_car.py`, `sdf.py` -> `assets/props.bin`, `cabin.as` |
| Facade and roof textures | `tools/make_tex.py` (from `art/src`) -> `assets/tex.bin`, `texinfo.as` |
| Window maps for the facades | `tools/make_winmap.py` -> `assets/win.bin` |
| Compressed mesh packs | `tools/zpack.py` -> `assets/*.rz` (decoded in-engine by `inflate.as`) |

### Rebuilding from source

Python 3.9 or newer (the pinned versions in `requirements.txt` reproduce the shipped assets byte for byte):

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python tools/make_tex.py
.venv/bin/python tools/make_city.py
.venv/bin/python tools/make_props.py
.venv/bin/python tools/make_winmap.py
.venv/bin/python tools/zpack.py assets/city.bin assets/city.rz     # optional: compressed packs
.venv/bin/python tools/zpack.py assets/props.bin assets/props.rz
.venv/bin/python tools/gen.py
.venv/bin/python tools/build_world.py
rive . --aot
```

`gen.py` uses the raw `.bin` packs when they exist (fastest local loads) and the compressed `.rz` packs
otherwise. `WEB=1 tools/gen.py` builds the variant meant for `rive . --publish=web` (compressed packs and
glyph-subset fonts).
